# JobsShadow · 乔布斯 1995 访谈 · 影子跟读训练器

一个**纯前端、零后端、数据只留在你本机浏览器**的英语影子跟读（shadowing）工具。
为"只练乔布斯一个人、练透 1995 年那场访谈"这个目标专门做的：可精确抠片段、变速、循环、录音、和原声并排对比，并用**连续天数 + 每日目标 + 提醒**督促你每天练。

## 为什么这么设计

模仿一个人其实要分两层：**发音底座**（节奏 / 连读 / 重音 / 语调）和**表达气场**（叙事 / 停顿 / 感染力）。
乔布斯 1995 年的访谈两样都能练。工具把公认的高效方法固化成流程：

1. **纯听** — 不看字，抓整体节奏与语调
2. **对文听读** — 看字幕跟读，标连读/重音
3. **同步影子** — 滞后半秒同步说出来（核心）
4. **脱稿影子** — 不看字，只靠听
5. **录音对比** — 录下自己，和原声并排听，找 3 个最大差距，第二天专攻

> 关键纪律：**同一个片段至少练一周**；**每次必录音对比**。进步来自重复到肌肉记忆，不是数量。

## 📱 在手机上用（推荐 · GitHub Pages，无需进设置页）

这是 **GitHub**（不是 GitLab）。手机录音需要 **HTTPS**，所以把它挂到 GitHub Pages 得到一个手机能直接打开的网址即可。仓库里已带好自动部署工作流（`.github/workflows/jobs-shadow-pages.yml`），并且**会自动开启 Pages**（`enablement: true`），所以你**不用去找 Settings→Pages 那个页面**（GitHub 手机 App 里本来也没有它）。

**最简单的办法（手机 App 就能做）：把这个 PR 合并进 `master`。**

1. 在 GitHub App 里打开本 PR → 点 **Merge**（合并）。
2. 合并会自动触发部署：工作流在 `master` 上运行，自动开启 Pages 并发布。
3. 约 1–2 分钟后，手机浏览器打开：**`https://jun122013.github.io/minimind/`**
4. 第一次录音会弹麦克风授权，点允许。**iPhone 用 Safari，安卓用 Chrome。**

> 想改用网页版操作也行（手机浏览器登录后可直达）：
> - Pages 设置：<https://github.com/Jun122013/minimind/settings/pages>（找不到就点浏览器菜单「请求桌面网站」）
> - Actions（看部署进度/手动触发）：<https://github.com/Jun122013/minimind/actions>
>
> 部署成功后，把网址"添加到主屏幕"，就像一个 App 一样天天点开练。

## 在电脑上用（本地）

因为录音需要"安全上下文"，本地请用服务器方式打开（否则部分浏览器会禁用麦克风）：

```bash
cd jobs-shadow
python3 -m http.server 8080
```

然后浏览器访问 <http://localhost:8080> 。

> 只想看界面、不录音的话，直接双击 `index.html` 也能用（但录音可能被浏览器拦截）。

## 手机兼容性说明

- **iPhone / Safari**：录音用的是 `MediaRecorder`，工具会自动选 Safari 支持的 `audio/mp4` 格式（不再写死 `webm`），录完可回放/下载为 `.m4a`。
- **YouTube 模式**：手机上 YouTube 播放需要你点一下播放（浏览器的自动播放限制），之后变速/循环正常。
- 若手机上录音没反应：确认你用的是 **https 网址**（不是别人电脑的 `localhost`），且已授予麦克风权限。

## 载入 1995 访谈

有两种方式：

- **YouTube 模式（默认）**：点页面里的搜索链接找到那场访谈（关键词已预填 “Steve Jobs 1995 interview taste / lost interview”），把链接粘进输入框点「载入」。
- **本地文件模式**：把访谈音频/视频下载到本地，选「本地文件」上传——此模式**完全离线**、变速更精准。

## 校准片段时间戳

不同上传源的时间轴不一样，所以工具不写死时间，让你**一次性校准**：

1. 载入视频后播放到某句话开头，点「设为起点」；到结尾点「设为终点」。
2. 之后点「播放此片段」就只播这一段；开「A-B 循环」可无限重复。
3. 已预置著名的 **“no taste” 片段文本**（谈 Microsoft 那段）；另有两个空片段模板，你边听边把原句补进「片段」页即可。

## 功能

- 🎯 精确片段：起/终点校准、A-B 循环、0.5×–1× 变速
- 🎙 录音 + 实时波形、**音高(Hz)** 与音量表，帮你逼近音色/节奏
- ⇄ 一键「原声 → 我的」顺序对比
- 🔥 连续天数、最长连击、累计分钟、**练习热力图**
- ⏰ 每日目标 + 定时浏览器提醒（页面打开时生效）+ 打开即督促横幅
- 💾 全部数据存本地；支持导出/导入迁移（录音不入库，可单独下载）

## 局限（诚实说明）

- **提醒**：受浏览器限制，**页面关闭时无法主动推送**。定时通知只在页面开着时触发；平时靠"连续天数不能断"的心理压力 + 打开页面时的横幅督促你。若要真正的关屏推送，需要额外接入 Service Worker Push + 推送服务（本工具未做）。
- **音色对比**：提供的是波形 + 音高的直观参照，不是声学级 formant 比对。先让"曲线形状/节奏"贴近，再抠音色。
- **版权**：仅预置了被广泛引用的一句 "no taste" 文本用于个人学习；访谈音视频请自行合法获取，不随工具分发。

## 技术

纯静态：`index.html` + `styles.css` + `app.js`（原生 JS，无构建、无依赖）。
YouTube IFrame API 用于变速/定位；`getUserMedia` + `MediaRecorder` + `AnalyserNode` 用于录音与可视化；`localStorage` 存进度。
